# StarBurst (Android)

**Нативний Android-клієнт для AI-агентів програмування (розмовляє протоколом, сумісним з
OpenCode V2)**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Min SDK](https://img.shields.io/badge/minSdk-26-brightgreen)]()
[![Platform](https://img.shields.io/badge/Platform-Android-blue)]()

**[English](README.md) · [Simplified Chinese](README.zh-CN.md) · Українська**

</div>

StarBurst — багатий на функції нативний клієнт Material 3, що дозволяє керувати AI-агентом
програмування з телефона чи планшета. Під'єднуйтеся до будь-якого сервера, що розмовляє
протоколом, сумісним з OpenCode (включно з серверами OpenCode), через мережу, спілкуйтеся з
агентом, переглядайте файли робочого простору, запускайте повноцінний термінал і керуйте
сесіями — усе з орієнтованого на мобільні UI.

> Це проєкт спільноти, не афілійований з офіційною командою.

---

## ✨ Можливості

- **Нативний чат** — UI на Material 3 з GFM Markdown, блоками коду, підсвіткою синтаксису та
  діями копіювання
- **Потокова передача в реальному часі** — повідомлення транслюються наживо з автопрокруткою
- **Локальні підказки** — підказки наступних кроків генеруються **повністю офлайн** локальною
  моделлю MNN (Qwen3.5-0.8B). Ваги завантажуються з **ModelScope** при першому використанні
  (швидко в материковому Китаї) з перевіркою SHA-256 по кожному файлу; release-збірки, у які
  попередньо покладено `app/src/main/assets/models/`, натомість автоматично розпаковують їх з
  APK. З налаштованим бекендом підказки надають перевагу **спершу бекенд-LLM**, потім зовнішньому
  провайдеру, потім локальній моделі — кожне джерело підписане
- **Локальний голосовий ввід** — розпізнавання мовлення з затиснутою кнопкою на базі локальної
  моделі **MNN sherpa-mnn streaming Zipformer (двомовна zh/en)**, завантаженої з ModelScope (з
  перевіркою SHA-256 по кожному файлу). Затисніть, щоб говорити, відпустіть, щоб заповнити
  введення, проведіть угору для скасування, з живою хвилею гучності. Кнопка мікрофона з'являється
  лише після завантаження моделі в Налаштуваннях
- **Зовнішній LLM-провайдер** — принесіть власний endpoint, сумісний з OpenAI
  (`/v1/chat/completions`), для генерації підказок з автоматичним безшумним резервним переходом
  на локальну модель. Кнопка **Test connection** надсилає реальну однотисову розмову та показує
  відповідь моделі
- **Посилання розмов** — посилання на під'єднаний сервер відкриваються у вбудованому WebView
  (з Basic Auth); всі інші посилання залишають системному браузеру, тож облікові дані не витікають
- **Git** — вбудована сторінка Git (з меню ⋮ чату, коли проєкт є репозиторієм) з гілкою/станом,
  списком змін і diff, історією комітів та операціями commit/push/pull/checkout/гілка — плюс
  AI-генерація повідомлень комітів (хмарна LLM з резервним переходом на локальну)
- **Огляд проєкту** — пункт меню ⋮ чату, що сканує каталог проєкту сесії та показує статистику
  файлів/рядків за типом (код/коментарі/порожні), найбільші файли та інформацію про
  Git-репозиторій (гілка, кількість комітів, останній коміт, змінені файли та diffstat)
- **Керування серверами та провайдерами** — інформація про сервер (версія/активні сесії),
  CPU/пам'ять/диск, перегляд/редагування конфігурації, перезапуск та керування власними
  провайдерами (додавання/редагування/видалення провайдерів і моделей)
- **Редагування файлів** — редагування та збереження файлів робочого простору в застосунку
- **Резюме розмов** — резюме окремого повідомлення або цілої сесії через хмарну LLM (з резервним
  переходом на локальну), транслюються наживо
- **Акцентний колір і схеми тем** — одинадцять брендових акцентних палітр плюс п'ять повних
  схем тем (**Candy / Ocean / Sunset / Flame / Bubble**), що перефарбовують увесь застосунок,
  застосовуються по всьому додатку (світла/темна/AMOLED) та синхронізуються
- **Закладки та повнотекстовий пошук** — закладки ключових повідомлень та повнотекстовий пошук
  повідомленнями сервера (обидва в межах поточного сервера)
- **Центр завдань (starburst-backend)** — фонові завдання, пакетні запуски та архіви з
  AI-розбором плану, плануванням і блокуванням залежностей; бекенд виявляється автоматично з
  встановленням одним дотиком через SSH за відсутності
- **Файли робочого простору** — перегляд папок проєкту, попередній перегляд підсвіченого тексту,
  Markdown та зображень, завантаження файлів
- **Вкладення** — надсилайте зображення, PDF, текст, вихідний код і конфігураційні файли з
  пам'яті пристрою
- **Термінальний режим** — повноекранний термінал з PTY через WebSocket
- **Керування сесіями** — пошук, обране, категорії, форк, стиснення, поширення, експорт,
  видалення та закріплення сесій з новою активністю; глобальний пошук між серверами/проєктами;
  перетягування закріплених сесій; часовий фільтр пошуку
- **Керування моделями й агентами** — пошук провайдерів/моделей, циклічне переключення агентів,
  перегляд використання токенів і контексту. Верхня панель чату показує **сукупне використання
  токенів і витрати сесії**, тоді як кільце бюджету та діалог зайнятості контексту показують
  **поточну зайнятість контексту** (оцінка токенів / вікно моделі) — два різні числа, більше без
  хибного прочитання кумулятивних токенів
- **Оптимізація батареї** — WakeLock утримується лише поки сесія активно працює (busy/retry), а
  не під час фонового простою; усе фонове опитування (статус чату, хвіст журналу, керування
  сервером, список сесій, робочий стіл) призупиняється у фоні та відновлюється при поверненні
- **Кілька серверів** — під'єднання до кількох серверів одночасно зі стабільним
  перепідключенням і перемиканням одним дотиком зі списку сесій
- **AI-робочий стіл** — жива панель активності агентів між сесіями: потік подій у реальному
  часі, останній статус на сесію та панель рішень з останньою відповіддю AI, питаннями, що
  чекають (відповіді одним дотиком), редактором швидких відповідей з голосовим вводом і
  переходом у сесію
- **Дзеркало бекенду та живий push (starburst-backend)** — канал живих подій/сповіщень та
  AI-робочий стіл йдуть через дзеркало `/api/opencode/*` бекенду, коли воно досяжне (з резервним
  прямим шляхом), тоді як REST-виклики чату та списку сесій досі з'єднуються з сервером
  напряму (Basic auth); записує події сесій і надсилає сповіщення завершення / питань /
  дозволів / помилок зі звуком, вібрацією та банерами heads-up, навіть поки сесія відкрита
- **Віджет головного екрана та ярлики застосунку** — знімок сесій/серверів/завдань з глибокими
  посиланнями, плюс ярлики за довгим натисканням (нова сесія / глобальний пошук / центр
  завдань)
- **SSH-тунель** — опційно під'єднання та перезапуск сервісу сервера через SSH-тунель з
  моніторингом стану з'єднання (затримка/heartbeat/статус)
- **Власні Slash-команди** — визначайте команди `/name`, що вставляють підказку, зі збереженням
  та керуванням з панелі вводу чату
- **Адаптивне розташування** — дві панелі (список сесій + чат) на складаних і планшетах, одна
  панель на телефонах
- **Налаштування** — секції з карток, мова, тема, динамічний колір, темний AMOLED, акцентний
  колір, сповіщення, вібрація та більше
- **Безпечні оновлення** — APK з GitHub Release з перевіркою SHA-256, пакета, версії та
  сертифіката підпису

## 🚀 Початок роботи

### Вимоги

- Android 8.0+ (API 26)
- Сервер, досяжний у вашій мережі

### 1. Запустіть сервер

```bash
opencode serve --port 4096 --hostname 0.0.0.0   # референсний сервер; підійде будь-який сервер, сумісний з OpenCode V2
```

### 2. Під'єднайтеся в застосунку

1. Торкніться **+** на головному екрані
2. Введіть URL сервера (наприклад, `http://192.0.2.10:4096`), ім'я користувача та опційний
   пароль
3. Торкніться **Connect**

### 3. (Опційно) Налаштуйте зовнішню LLM для підказок

Типово «Generate suggestions» працює на вбудованій **локальній моделі MNN** (офлайн). Для
кращих підказок можна опційно налаштувати власну хмарну LLM:

1. Відкрийте **Налаштування → Suggestion service**
2. Заповніть **Base URL** (сумісний з OpenAI, наприклад `https://api.openai.com/v1`) —
   застосунок додає `/chat/completions`, тож вкажіть префікс, специфічний для провайдера,
   як-от `/v1`, якщо потрібно
3. Заповніть **Model** та **API Key**
4. Торкніться **Test connection** — це надішле просту однотисову розмову та покаже реальну
   відповідь моделі, з дружніми повідомленнями про помилки автентифікації, 404, тайм-аутів,
   DNS та зіпсованих URL — потім торкніться **Save**

Після налаштування підказки генеруються вашим хмарним провайдером; якщо він недосяжний або
нічого не повертає, застосунок **безшумно переходить** на локальну модель. Ваш API-ключ
шифрується Android Keystore і ніколи не залишає пристрій у відкритому вигляді.

### 4. (Опційно) Встановіть допоміжний бекенд (starburst-backend)

Застосунок працює і з голим сервером. Для бонусних функцій — **Центру завдань**
(фонові завдання / пакетні запуски / архіви з AI-розбором плану), **живого push подій**
(сповіщення завершення / питань / дозволів / помилок), живого дзеркала **AI-робочого столу** та
**статистики використання токенів** — застосунок автоматично виявляє супутній
**starburst-backend** (типово `http://<server>:18880`) і пропонує **встановлення одним дотиком
через SSH**, якщо його немає. Бекенд веде канал живих подій та робочий стіл через своє
дзеркало `/api/opencode/*` з резервним прямим шляхом до сервера, коли воно недосяжне, і
залишає REST-виклики чату / списку сесій під'єднаними просто до сервера (Basic auth). Якщо
starburst-backend працює на порту, відмінному від 18880, введіть `backendUrl` явно в
налаштуваннях сервера.

## 🔨 Збірка

### Android Studio

1. Відкрийте проєкт і синхронізуйте Gradle (використовується вбудований набір CMake/NDK)
2. Запустіть на пристрої або емуляторі

### Командний рядок

```bash
# Debug APK
./gradlew assembleDebug

# Release APK
./gradlew assembleRelease

# Встановлення на під'єднаний пристрій
adb install -r app/build/outputs/apk/release/app-release.apk

# Юніт-тести
./gradlew testDebugUnitTest
```

> Release-збірка лінкує нативні бібліотеки MNN, тож перша збірка триває кілька хвилин. Ваги
> моделей у `app/src/main/assets/models/` у gitignore і ніколи не комітяться, тож збірка зі
> свіжого клона працює нормально й завантажує модель (~520 МБ) з **ModelScope** при першому
> використанні. Попереднє покладення цього каталогу перед збіркою замість цього вшиває ваги
> в APK.

## 🏗️ Архітектура

### Структура

```
app/src/main/
├── cpp/                    # C++ шар
│   ├── starburst_mnn_jni.cpp  # JNI-обгортка (load / streaming generate / reset / release)
│   ├── CMakeLists.txt        # Лінкує нативні бібліотеки MNN
│   └── include/              # Заголовки MNN 3.6.1 (версії закріплені за .so)
├── jniLibs/                # Передзбіраний рантайм MNN (libMNN, libllm, …) + libsherpa-mnn-jni.so (ASR)
├── assets/models/          # Локальна Qwen3.5-0.8B (MNN) + конфігурація + токенізатор
└── kotlin/org/hiylo/starburst/
    ├── data/api/           # API сервера + SuggestionProvider (зовнішня LLM)
    ├── data/repository/    # EventReducer, налаштування, репозиторії серверів/сесій
    ├── data/sync/          # Синхронізація між пристроями (gist/webdav) + секрети під Keystore
    ├── ml/MnnLlm.kt        # Kotlin-обгортка локальної моделі
    ├── ml/MnnAsr.kt        # Kotlin-обгортка локальної моделі ASR (Zipformer)
    ├── ml/MnnAsrRecorder.kt# Потокове введення AudioRecord у розпізнавач ASR
    ├── service/            # Сервіс foreground-з'єднання (SSE + перепідключення) + SshRunner
    └── ui/                 # Compose UI: home, chat, sessions, settings, navigation
```

**Інтеграція з бекендом** — опційний **starburst-backend** (його Go-джерела див. у
`../opencode-backend/`) — супутній сервіс, що розширює сервер, не замінюючи його:

```
Chat / session list ──────────────► server (REST, Basic auth)            # прямий шлях
Live events / notifications ─────► starburst-backend :18880 /api/opencode/* # дзеркало, резерв — прямий
AI workbench ─────────────────────► starburst-backend :18880 /api/opencode/* # дзеркало, резерв — прямий
Tasks / archives / token stats ──► starburst-backend :18880 /api/*          # лише бекенд
```

Застосунок автоматично виявляє бекенд і пропонує встановлення одним дотиком через SSH; усе
деградує до прямого з'єднання, коли бекенд недосяжний.

**Конвеєр підказок**

```
User taps "Generate suggestions"
  ├─ External LLM configured?
  │    ├─ YES → POST {baseUrl}/chat/completions   (OpenAI-compatible)
  │    │        ├─ success → show cloud suggestions
  │    │        └─ fail/timeout/empty → fall through
  │    └─ NO/fallback → on-device MNN (Qwen3.5-0.8B, fully offline)
  └─ both fail → localized template suggestions
```
