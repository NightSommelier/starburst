# StarBurst v1.3.0 - Примітки до релізу

Цей реліз додає колірні схеми тем, підказки з пріоритетом бекенду, Центр завдань на базі
starburst-backend, віджет головного екрана, закладки та повнотекстовий пошук, серверний ASR та
встановлювач бекенду одним дотиком — плюс важливе виправлення нативної пам'яті.

## Основне

- **Колірні схеми тем** — три повні мультяшні колірні схеми (**Candy / Ocean / Sunset**), що
  перефарбовують увесь застосунок (поверхні, контейнери, вторинні/третинні кольори), плюс п'ять
  додаткових акцентних кольорів у циклічній палітрі.
- **Підказки з пріоритетом бекенду** — підказки наступних кроків тепер спершу пробують LLM,
  налаштований на бекенді, потім зовнішнього провайдера застосунку, потім локальну модель MNN;
  область підказок показує джерело (сервер / хмара / на пристрої / резервне).
- **Центр завдань** — фонові завдання, пакетні запуски та архіви через starburst-backend, з
  AI-розбором плану (потоковим), плануванням ( негайно / з затримкою / у визначений час / cron),
  блокуванням/розблокуванням залежностей та очищенням завершених завдань.
- **Віджет головного екрана та ярлики застосунку** — знімки сесій/серверів/завдань з глибокими
  посиланнями (відкрити сесію / під'єднати сервер / нова сесія / пошук / центр завдань), плюс
  ярлики за довгим натисканням.
- **Закладки та повнотекстовий пошук** — закладки повідомлень та повнотекстовий пошук між
  сесіями, обидва в межах поточного сервера (вхід у верхній панелі списку сесій).
- **Виявлення бекенду та встановлення одним дотиком** — сторінка налаштувань сервера опитує
  `/api/health`; якщо бекенд відсутній і налаштовано SSH, один дотик встановлює його через SSH
  та повторно перевіряє.
- **Серверний ASR** — потокове розпізнавання мовлення через рушій бекенду як резерв, коли
  локальна модель недоступна.

## Виправлення

- **Вибух нативної пам'яті (~790МБ)** — прибрано безумовне попереднє завантаження моделі MNN при
  відкритті чату; модель тепер завантажується на вимогу (нативна купа ~790МБ → ~21МБ).
- Дублювання відлуння при голосовому вводі та пізні записи корекцій після надсилання.
- Висота багаторядкового вводу та кнопка надсилання фіксованого розміру.
- Самовідновлення при зупинці SSE (резервне REST-опитування у періоди активності).
- Розмір шрифту на сторінці навичок (SKILL.md).
