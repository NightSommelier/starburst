# StarBurst v1.0.0 - Примітки до релізу

Перший реліз клієнта StarBurst.

## Основне

- Нативний чат-інтерфейс на Material 3 з markdown, блоками коду та підсвіткою синтаксису
- Потокова передача повідомлень у реальному часі з автопрокруткою
- **Локальні підказки** — підказки для наступних кроків генеруються повністю офлайн за допомогою
  вбудованої моделі MNN, з опційним зовнішнім LLM-провайдером, сумісним з OpenAI, та безшумним
  резервним перемиканням
- Браузер файлів робочого простору з попереднім переглядом та завантаженням
- Повноекранний термінальний режим з PTY через WebSocket
- Керування сесіями: пошук, обране, категорії, форк, поширення, експорт та видалення
- Завершені, але непрочитані сесії закріплюються вгорі списку сесій
- Підтримка кількох серверів зі стабільним перепідключенням
- Адаптивне двопанельне розташування на складних та планшетах
- Керування темою, динамічним кольором, AMOLED та сповіщеннями
- Безпечні оновлення в застосунку з перевіркою SHA-256 та сертифікатом підпису
