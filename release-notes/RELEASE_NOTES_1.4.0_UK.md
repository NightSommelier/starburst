# StarBurst v1.4.0 - Примітки до релізу

Цей реліз додає екрани керування сервером (правила автоматизації / API-токени / журнал аудиту),
повноцінний робочий процес AGENTS.md, навігацію гілками форків, швидкі шаблони підказок та
продовжує перейменування проєкту на StarBurst.

## Основне

- **Керування сервером** — три нові екрани в налаштуваннях сервера:
  - **Правила автоматизації** — завдання агентів за розкладом / git / webhook з генерацією
    природною мовою через AI (`/api/rules/generate`) та історією виконання.
  - **API-токени** — створення / відкликання токенів доступу до бекенду (відкритий текст
    показується один раз).
  - **Журнал аудиту** — нещодавні автентифіковані дії API.
- **Робочий процес AGENTS.md** — з меню чату: виявлення `AGENTS.md` проєкту, потім ** генерація**
  (файлу немає), **покращення** (AI-удосконалення), **зміна за інструкцією** (природною мовою)
  або **ручне редагування** зі збереженням назад у корінь проєкту. Генерація показує анімований
  індикатор стану, а збої пропонують повторну спробу «Продовжити».
- **Продовження після збою** — коли агент перериває роботу або повторна спроба зазнає невдачі,
  повідомлення про помилку пропонує дію «Продовжити», що відновлює сесію.
- **Навігація гілками форків** — панель гілок дозволяє стрибати між сесією та її форкнутими
  дочірніми сесіями і назад до батьківської.
- **Повторне копіювання посилання поширення** — для вже поширених сесій URL поширення можна
  скопіювати знову з меню.
- **Швидкі шаблони підказок** — пресети одним дотиком (огляд коду / згенерувати тести / пояснити
  код / виправити баг) заповнюють редактор; зручно на мобільному.

## Змінено

- **Перейменовано на StarBurst** — application id `org.hiylo.starburst`, назва застосунку
  **StarBurst**, новий keystore для підпису.
- **Пріоритет серверного ASR** — голосовий ввід тепер надає перевагу потоковому рушію бекенду з
  резервним переходом на локальну модель MNN.
- **«Сервіс підказок» → «LLM-сервіс»** — налаштування провайдера відображає його ширшу роль.
- **Розділення вихідного коду** — ChatScreen / NavGraph / OpenCodeApi розбито на файли за
  зонами відповідальності.

## Виправлення

- Виявлення порожнього файлу AGENTS.md (сервер повертає 200 + порожній вміст для відсутніх
  файлів).
- Розташування редактора AGENTS.md, що виштовхував кнопку збереження за межі екрана.
- Endpoint'и статистики / аудиту / правил / токенів тепер приймають токен застосунку.
