# StarBurst v1.0.1 - Примітки до релізу

Цей реліз додає вбудовану роботу з Git та вдосконалює візуальний дизайн.

## Основне

- **Сторінка Git** — відкрийте Git під'єднаного проєкту з меню ⋮ чату (показується, коли проєкт
  є репозиторієм). Переглядайте поточну гілку та стан робочого простору, список змін з diff по
  кожному файлу (включно з невідстежуваними файлами) та історію комітів зі змінами файлів по
  кожному коміту та diff по кожному файлу.
- **Операції Git** — commit, push/pull (з вибором remote за наявності кількох), перемикання
  гілки та створення гілки — усе через постійну термінальну сесію для швидкого відгуку.
- **AI-повідомлення комітів** — генеруйте повідомлення коміту на основі нещодавнього стилю
  комітів за допомогою налаштованої хмарної LLM з резервним переходом на локальну модель.
- **Завантаження моделей з ModelScope** — локальна модель тепер завантажується з ModelScope
  (швидко в материковому Китаї) з перевіркою SHA-256 по кожному файлу; за наявності в білді вона
  автоматично розпаковується з ресурсів APK.
- **Вирівнювання дизайну** — кольорові бейджі статусу сесій, семантичні кольори статусів та
  уніфіковані заокруглення карток/рамки AMOLED.

## Виправлення

- Вбудована локальна модель ніколи не використовувалася під час виконання (завжди пропонувалося
  завантаження).
- Git-дані хибно повідомляли «not a repository», а PTY-команди могли губитися або спливати за
  часом.
