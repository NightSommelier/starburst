# StarBurst v3.0.0 - Примітки до релізу

Випущено 2026-09-21. Стартує напрямок **Test Intelligence**, плюс великі клієнтські доповнення:
огляд проєкту, оптимізація батареї, опитування з урахуванням життєвого циклу, набір E2E-тестів,
заокруглений мультяшний стиль та доопрацьована тема Flame.

## Основне

- **Огляд проєкту** — новий пункт у меню ⋮ верхньої панелі чату. Сканує каталог проєкту сесії та
  показує статистику файлів/рядків за типом (код/коментарі/порожні), найбільші файли та
  інформацію про Git-репозиторій (гілка, кількість комітів, останній коміт, змінені файли та
  diffstat). Сканування на боці shell використовує `find | xargs wc -c` + awk-класифікатор рядків
  з виявленням коментарів у C-стилі та `#`-стилі.
- **Мультяшний стиль: заокруглений шрифт заголовків + оформлення іконок** — заголовки та
  підписи перемикаються на вбудовану родину Baloo 2 (SIL OFL, 3 насиченості, лише латиниця,
  ~268КБ), а іконки отримують два обгортки (`CartoonInkIcon` чорнильний гліф,
  `CartoonStickerIcon` нахилена плитка з жорсткою тінню); текст `body*`, код і китайський текст
  залишаються на системному шрифті / монопросторовому. Повідомлення OFL постачається в
  `assets/licenses/Baloo2-OFL.txt`.
- **Мультяшний стиль: шкала `MaterialTheme.shapes`** — уся шкала форм підмінюється, поки
  мультяшний стиль увімкнений, тож компоненти M3, які ніколи не мали адаптивної форми (картки,
  снекбари, текстові поля з контуром, чіпи, FAB, випадні меню), теж заокруглюються.
- **Список сесій: пакетне стиснення** — дія Compress у верхній панелі багатовибору резюмує всі
  вибрані сесії одночасно (кожна зі своєю моделлю, з резервним переходом на типову серверну),
  щоб зменшити контекст — дзеркально до пункту меню Compact окремої сесії.
- **Оптимізація батареї** — WakeLock тепер утримується лише коли сесія активно працює
  (busy/retry), а не в фоновому режимі простою; інтервал WS ping 20с→60с; release-збірки більше
  не зберігають INFO-журнали в SQLite; типове значення `backgroundWakeLock` змінено на false.
- **Опитування з урахуванням життєвого циклу** — усе фонове опитування (статус чату, хвіст
  журналу, керування сервером, список сесій, робочий стіл) тепер призупиняється, коли застосунок
  у фоні, через `launchWhileStarted` (repeatOnLifecycle), з відновленням після повернення.
- **Використання токенів у верхній панелі** — підзаголовок верхньої панелі чату тепер показує
  сукупне використання токенів сесії (весь ввід + вивід), що відрізняється від кільця бюджету в
  панелі вводу (поточне заповнення контексту).
- **Тема Flame** — переналаштована на насичений пристрасний червоний: primary `#FF1744`
  (Red A400), secondary `#FF6D00` (Orange A700), tertiary `#D50000` (Red A700).
- **Набір E2E-тестів** — 5 потоків Maestro (smoke, add-server-connect, session-list, settings,
  workbench) з пакетним запускачем (`scripts/run-e2e.sh`) та `.secrets-allowlist`.
- **Обрізання назв моделей** — довгі назви моделей більше не виштовхують кільце бюджету за
  межі екрана; обрізаються на 24 символах з багатобезпечною (surrogate-pair-safe) крапкою.

## Змінено

- Підзаголовок верхньої панелі показує сукупне використання токенів (весь ввід + вивід) та
  витрати, окремо від кільця бюджету панелі вводу (поточна заповненість контексту / ефективне
  вікно).
- Палітра теми Flame переналаштована на більш насичений червоний.
- Опис мультяшного стилю в Налаштуваннях → Вигляд згадує заокруглений шрифт заголовків та
  іконки з чорнильним контуром (обидві мови).
- Найбільші Kotlin-джерела розділено за відповідальністю; жоден файл не перевищує жорсткої межі
  1500 рядків.
- CI запускає JVM-юніт-тести на кожен push/PR (`./gradlew test` на JDK 17) + gitleaks + захист
  розміру файлів.
- Завантаження сесії розпаралелено: BFS дочірніх сесій, стан git та початковий diff виконуються
  конкурентно.
- Статус непрочитаного тепер керується push (прибрано резервне опитування кожні 10с).

## Додано

- Огляд проєкту (статистика файлів/рядків + інформація про Git-репозиторій) у меню ⋮ чату.
- Мультяшний стиль: заокруглений шрифт заголовків (Baloo 2, OFL), обгортки іконок
  inked/sticker та шкала `MaterialTheme.shapes`.
- Compress для багатовибору в списку сесій (пакетне стиснення).
- Шаблони підказок та сесій, часова шкала сесії, власний системний промпт + бюджет контексту.
- Переглядач diff файлів, AI-дії в редакторі, локальна допомога з коду (MNN).
- Живий хвіст журналу сервісу, теги та групи закладок, зашифроване резервне копіювання та
  відновлення.
- Картка використання токенів, швидкі дії сповіщень (RemoteInput).
- Інфраструктура E2E-тестів (5 потоків Maestro + пакетний запускач).
- Утиліта опитування з урахуванням життєвого циклу (`launchWhileStarted`).

## Безпека

- Перевірка host-ключа SSH (known_hosts TOFU).
- Конфігурація сервера шифрується в стані спокою (Android Keystore AES-GCM) з міграцією зі
  застарілого відкритого тексту.
- Паролі прибрано з Intents/PendingIntents.
- Захист WebView (без mixed content, зовнішні посилання в браузері, перевірка хоста HTTP-auth).
- Скрипт встановлення закріплений за release-тегом з рандомізованим токеном бекенду.
- **Необхідна версія бекенду підвищена до 2.0.1** — встановлення одним дотиком тепер тягне
  `install.sh` з тегу `v2.0.1`, який перевіряє завантажений бінарник проти `SHA256SUMS`
  релізу (при невідповідності — переривання та видалення часткового файлу). v2.0.0 також
  виправляє поломку назви артефакта, через яку встановлення з v1.0.0/v1.1.0 давало 404
  (`startburst-backend-*` → `starburst-backend-*`), та відновлює відсутні ресурси
  `windows-amd64.exe` + `SHA256SUMS`.

## Виправлено

- Довгі назви моделей більше не виштовхують кільце бюджету за межі екрана (обрізання на 24
  символах).
- Hilt 2.51→2.52: виправлено збій у debug (`StarBurstApp_GeneratedInjector` NoClassDefFoundError)
  та відсутній клас R8 у release.
- Зависання з'єднання з сервером на «connecting» — блокуюча робота винесена за межі блокування
  з'єднання.
- Розсинхронізація стану з'єднання — прапорці тепер узгоджуються атомарно.
- Нативний доступ MnnLlm/MnnAsr серіалізовано під одним блокуванням (захист від use-after-free).
- Записувач ASR зупиняється при ViewModel clear (мікрофон не «тікає»).
- Батьківські сесії показувалися як idle, поки їхні дочірні субагенти ще працювали (список сесій
  та робочий стіл). Push-події дочірніх сесій більше не відкидаються — придушується лише
  сповіщення «відповідь готова», як в офіційному Web UI / TUI; список агрегує busy/retry
  дочірніх сесій на батьківській, а монотонний захист не дає запізнілому push `idle`
  перезаписати агрегований стан.

## Інженерія

- Юніт-тести (261 випадок) + Compose-інструментування (2 випадки) + Maestro E2E (5 потоків) —
  усе зелене.
- CI-захист розміру файлів (`scripts/check-file-size.sh`, жорстка межа 1500 рядків).
- Управління розміром файлів: найбільші джерела розділено на файли-розширення в тому ж пакеті.

## Парність із бекендом

Ця версія вимагає starburst-backend **>= 2.0.1** (`BackendGate.REQUIRED_BACKEND_VERSION`).

- Бекенд **v2.0.0**: Test Intelligence стає третьою основною можливістю; назву артефакта
  виправлено з `startburst-backend-*` на `starburst-backend-*` — уже опубліковані ресурси
  v1.0.0 / v1.1.0 досі мають стару назву, тому `install.sh` для них повертає 404.
- Бекенд **v2.0.1**: `install.sh` перевіряє завантаження проти SHA-256 (при невідповідності
  артефакт видаляється та виконання завершується).

Встановлення одним дотиком у застосунку тягне `install.sh` з тегу `v2.0.1`, тож перевірка
застосовується автоматично.

```bash
curl -fsSL https://raw.githubusercontent.com/hiylo/starburst-backend/v2.0.1/scripts/install.sh \
  | sudo env STARBURST_DEFAULT_TOKEN=<your-token> bash -- --port 18880 --version 2.0.1
```
