# StarBurst v1.1.0 - Примітки до релізу

Цей реліз додає керування серверами та провайдерами, редагування файлів робочого простору та
значно розширену роботу з Git.

## Основне

- **Керування серверами та провайдерами** — сторінка керування сервером (інформація про сервіс,
  CPU/пам'ять/диск, перегляд/редагування конфігурації, перезапуск) та керування провайдерами
  (додавання/редагування/видалення власних провайдерів з моделями), усе поверх спільної
  PTY-сесії рівня з'єднання.
- **Сторінка Git** — відкрийте Git під'єднаного проєкту з меню чату: вибір репозиторію,
  гілка/стан, список змін, історія комітів та операції commit/push/pull/checkout/гілка, з
  AI-генерацією повідомлень комітів.
- **Розширений Git** — вибіркове індексування, fetch/stash/tag, історія комітів з посторінковим
  завантаженням та індикатор непроштовхнутих комітів.
- **Редагування файлів** — редагування та збереження файлів робочого простору в застосунку.
- **Досвід чату** — дії з повідомленнями перенесено до меню кожного повідомлення, а резюме
  розмов (окремого повідомлення або всієї сесії) використовують хмарну LLM з резервним переходом
  на локальну модель та транслюються в реальному часі.
- **Вирівнювання дизайну** — кольорові бейджі статусу сесій та семантичні кольори статусів.

## Виправлення

- Перше відкриття Git могло хибно повідомляти «not a repository» (гоночні умови каталогу/PTY);
  тепер виконується автоматична повторна спроба.
- Локалізовано тости збереження/видалення провайдерів.
- Технічний борг: ліміт токенів для хмарного резюме/повідомлення коміту, вікно конкурентного
  запису конфігурації провайдера та переповнення base64-запису великих файлів.
