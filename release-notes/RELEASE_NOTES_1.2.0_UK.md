# StarBurst v1.2.0 - Примітки до релізу

Цей реліз додає локальний голосовий ввід, глобальний пошук, значно розширений список сесій та
SSH-тунелювання, а також низку виправлень списку сесій та архівів.

## Основне

- **Локальний голосовий ввід** — локальна модель **MNN sherpa-mnn streaming Zipformer
  (двомовна zh/en, int8)**, що завантажується з ModelScope з перевіркою SHA-256 по кожному файлу.
  Затисніть, щоб говорити, відпустіть, щоб вставити текст, проведіть угору для скасування, з
  живою хвилею гучності; мікрофон з'являється після завантаження моделі в Налаштуваннях.
- **Глобальний пошук** — агрегація кореневих сесій між серверами та проєктами з пошуком за
  назвою/каталогом/проєктом/гілкою та фільтром за часом.
- **Список сесій** — перемикання між серверами одним дотиком, перетягування закріплених сесій
  для перевпорядкування, фільтр пошуку за часом та компактне розташування, що повторює
  перемикач компактного режиму чату.
- **SSH-тунель та моніторинг стану** — опційний SSH-тунель (локальне портування JSch) для
  під'єднання та віддаленого перезапуску сервісу opencode, а також контроль стану з'єднання
  (затримка / heartbeat / статус).
- **Чат** — власні Slash-команди, цитування-відповідь та експорт сесії (Markdown / JSON).

## Виправлення

- Мерехтіння статусу / «зависла» розмова: опитування статусу більше не перезаписує активний
  стан `busy`; узгодження idle відбувається лише за відсутності з'єднання.
- Зворотна навігація в двопанельному режимі на складних тепер повертає до батьківської сесії.
- Список сесій більше не втрачає сесії з інших проєктів (endpoint кореневих сесій між проєктами +
  авторитетний знімок).
- Архівування/розархівування тепер набирає чинності через вкладене поле `time.archived`.
- Відкриття/створення сесії більше не стирає інші сесії зі списку.
- З'явився пункт завантаження голосової моделі (та мікрофон у чаті); виправлено залежність MNN
  у вбудованому ASR JNI.
